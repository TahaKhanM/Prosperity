# round3_manual_research

Simulation notebooks for the Round 3 manual trading puzzle, a sealed-bid
game against the field where the payoff depends on how many other teams bid
near your number.

- `bid1.ipynb`, `bid2.ipynb` model the two-bid version and search for the
  bid pair that maximizes expected profit against an assumed distribution of
  opponent bids.

The manual puzzles are independent of the algorithmic trader. Other rounds'
manual work lives under `prosperity-research/07_manual_round/`.
