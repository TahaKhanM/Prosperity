# 00_inbox

Purpose: hold untriaged notes, dropped files, and temporary material before it
is routed into a canonical stage directory.

Expected inputs: raw notes, ad hoc exports, screenshots, and partial analyses
that do not yet have a stable home.

Expected outputs: dated triage notes and routed artifacts copied or moved into
the correct stage directory.

Naming conventions: use `YYYY-MM-DD_<topic>.md` for triage notes. Keep source
filenames only until the item is routed.

Classification: ancillary notes directory.
