# 04_signal_notes

Purpose: capture post-EDA signal hypotheses and feature-ranking summaries that
feed strategy specification.

Expected inputs: EDA outputs, feature tables and updated assumptions.

Expected outputs: dated hypothesis notes and maintained feature-ranking
summaries in the leaf directories below this folder.

Naming conventions: use `YYYY-MM-DD_<topic>.md` for dated notes and
`latest_<topic>.md` only for intentionally maintained rolling summaries.

Classification: canonical stage artifact directory.

Existing loose top-level files remain valid historical material. New work should
go into the leaf directories.
