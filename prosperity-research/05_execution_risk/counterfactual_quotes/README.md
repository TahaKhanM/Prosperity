# 05_execution_risk/counterfactual_quotes

Purpose: capture studies of alternative quote placement, taking thresholds and
execution counterfactuals.

Expected inputs: candidate-vs-baseline results, persisted run artifacts and
order-book or trade-level diagnostics.

Expected outputs: counterfactual quote studies, markdown summaries and support
figures.

Naming conventions: use `YYYY-MM-DD_<topic>.md` and
`YYYY-MM-DD_<topic>_<view>.png`.

Classification: canonical stage artifact directory.
