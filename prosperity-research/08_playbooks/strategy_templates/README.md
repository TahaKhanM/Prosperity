# 08_playbooks/strategy_templates

Purpose: hold non-code strategy specifications that are ready to hand off into
implementation.

Expected inputs: validated hypotheses, execution-risk findings and baseline
requirements.

Expected outputs: strategy specs that define the intended behavior before trader
code changes are made in `prosperity_rust_backtester/`.

Naming conventions: use `<product_or_family>_strategy_spec.md`.

Classification: canonical stage artifact directory.
