# 08_playbooks

Purpose: hold non-code strategy specs, runbooks, and reusable prompt material
that connect research outputs to implementation.

Expected inputs: validated hypotheses, execution-risk findings, and baseline
requirements.

Expected outputs: strategy templates, runbooks, and prompt snippets in the leaf
directories below this folder.

Naming conventions: use `<product_or_family>_strategy_spec.md`,
`YYYY-MM-DD_<topic>.md`, and `current_<topic>.md` only for intentionally
maintained evergreen docs.

Classification: canonical stage artifact directory.
