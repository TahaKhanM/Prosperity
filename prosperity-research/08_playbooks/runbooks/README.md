# 08_playbooks/runbooks

Purpose: document repeatable human or agent operating procedures for research,
validation and diagnosis.

Expected inputs: stabilized workflow decisions, tooling caveats and lessons
from recent experiment logs.

Expected outputs: dated runbooks or maintained evergreen operating guides.

Naming conventions: use `YYYY-MM-DD_<topic>.md` and `current_<topic>.md` only
for intentionally maintained evergreen runbooks.

Classification: canonical stage artifact directory.
