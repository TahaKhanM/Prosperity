# Candidate Vs Baseline Review

```text
You are reviewing a candidate run against a baseline run on the same dataset.

Inputs:
- candidate_vs_baseline_metrics.csv
- candidate_vs_baseline_report.md
- diagnosis summaries for both runs if available

Task:
1. summarize the outcome delta
2. identify the most likely cause category
3. say whether to ship or reject
4. recommend exactly one follow-up change if rejected
5. name the metric that should improve next

Do not suggest multiple simultaneous strategy changes.
```
