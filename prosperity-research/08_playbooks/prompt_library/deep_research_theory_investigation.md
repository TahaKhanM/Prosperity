# Deep Research Input Prompt

```text
You are doing theory and resource investigation for IMC Prosperity.

Inputs:
- current assumption note
- analyzer handoff summary
- latest diagnosis packet or candidate-vs-baseline report

Task:
1. identify the single highest-value open research question
2. find theory or external patterns relevant to that question
3. separate official facts, local repo facts, and speculative ideas
4. convert the result into one testable hypothesis for the next iteration

Do not propose a new data pipeline or a large repo refactor.
```
