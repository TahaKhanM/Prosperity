# 08_playbooks/prompt_library

Purpose: store reusable prompt fragments and prompt packs that support repeatable
research or validation workflows.

Expected inputs: stable workflow needs, distilled assumptions, and lessons from
previous runs.

Expected outputs: dated prompt notes or maintained prompt packs ready for reuse.

Naming conventions: use `YYYY-MM-DD_<topic>.md` and `current_<topic>.md` only
for intentionally maintained evergreen prompts.

Classification: canonical stage artifact directory.
