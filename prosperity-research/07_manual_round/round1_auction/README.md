# 07_manual_round/round1_auction

Purpose: keep Round 1 manual auction notes and solver outputs separate from
algorithmic research artifacts.

Expected inputs: auction instructions, valuation reasoning, frozen-book
scenario files, and manual decision notes.

Expected outputs: solver runs under `<run_id>/` containing `payoff_grid.csv`,
`best_order_recommendations.md`, `sensitivity_notes.md`, plus any dated auction
writeups.

Naming conventions: use `<run_id>/payoff_grid.csv` for solver output folders
and `YYYY-MM-DD_<topic>.md` for supporting notes.

Classification: manual-challenge material directory.
