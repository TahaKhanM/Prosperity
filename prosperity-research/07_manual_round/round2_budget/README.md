# 07_manual_round/round2_budget

Purpose: keep Round 2 manual budget-game work and allocator outputs separate
from algorithmic research artifacts.

Expected inputs: manual round instructions, competitor speed assumptions,
scenario JSON files when needed and budget allocation notes.

Expected outputs: solver runs under `<run_id>/` containing `scenario_table.csv`,
`recommended_allocations.md`, `assumptions.md`, plus any dated writeups.

Naming conventions: use `<run_id>/scenario_table.csv` for solver output folders
and `YYYY-MM-DD_<topic>.md` for supporting notes.

Classification: manual-challenge material directory.
