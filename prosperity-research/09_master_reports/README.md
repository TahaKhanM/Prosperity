# 09_master_reports

Purpose: store synthesized long-form reports that combine findings across
multiple research stages.

Expected inputs: assumptions, EDA, validation, diagnosis and experiment-log
material that has already been distilled.

Expected outputs: long-form reports intended for broader review or handoff.

Naming conventions: use `YYYY-MM-DD_<topic>.md` for dated reports and
`current_<topic>.md` or `latest_<topic>.md` only for maintained rollups.

Classification: ancillary notes directory.
