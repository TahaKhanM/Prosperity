# 03_eda

Purpose: keep exploratory analysis notebooks, reusable figures, and
product-specific investigation notes.

Expected inputs: normalized datasets, feature datasets, and current assumptions.

Expected outputs: notebooks, figures, and per-product notes stored in the leaf
directories below this folder.

Round-specific analyzer packages can also live directly under this folder when
their code should stay with the research artifacts, for example
`prosperity-research/03_eda/round1/`.

Naming conventions: use `YYYY-MM-DD_<topic>.ipynb`,
`YYYY-MM-DD_<topic>_<view>.png`, and `YYYY-MM-DD_<product>_<topic>.md`.

Classification: canonical stage artifact directory.

Existing loose top-level files remain valid historical material. New work should
go into the leaf directories.
