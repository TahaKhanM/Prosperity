# 03_eda/per_product

Purpose: capture compact product-specific exploratory notes without mixing them
into broader notebooks or reports.

Expected inputs: notebook findings, feature slices, and normalized data views
for one product or product family.

Expected outputs: per-product markdown notes and small supporting figures.

Naming conventions: use `YYYY-MM-DD_<product>_<topic>.md` and
`YYYY-MM-DD_<product>_<view>.png`.

Classification: canonical stage artifact directory.
