# 01_assumptions

Purpose: record verified assumptions, source hierarchy and open questions that
gate downstream research.

Expected inputs: official competition docs, repo/tooling caveats and findings
from prior validation or diagnosis work.

Expected outputs: dated assumption notes and maintained rollups such as
`current_<topic>.md` where that pattern is already in use.

Naming conventions: use `YYYY-MM-DD_<topic>.md` for dated notes and
`current_<topic>.md` for intentionally maintained rollups.

Classification: canonical stage artifact directory.
