# 06_validation/candidate_vs_baseline

Purpose: record explicit ship-or-reject comparisons between a candidate and a
named baseline.

Expected inputs: implementation outputs, baseline snapshots, and persisted run
artifacts when needed.

Expected outputs: comparison writeups that state whether the candidate should
advance or be rejected.

Naming conventions: use `YYYY-MM-DD_<candidate>_vs_<baseline>.md`.

Classification: canonical stage artifact directory.
